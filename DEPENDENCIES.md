No maintained fork is required. No upstream PR is known or required. Production readiness is withheld until API shapes, supported-version behavior, Ingress identity/admin enforcement, restart disconnect recovery, and manual rollback/confirmation are tested against an actual supported HA installation. HA has no atomic conditional configure operation, so an external concurrent edit may race the immediate recheck and write.
